# 영역 캡쳐 프로그램

**Ctrl+Shift+A**를 누르고 드래그하면 그 영역을 캡쳐합니다.

- `사진\캡쳐` 폴더에 PNG로 저장합니다.
- 클립보드에 파일과 이미지를 같이 복사합니다.
  - 탐색기에서 Ctrl+V를 하면 파일이 붙여넣어집니다.
  - 카톡, 그림판, 엑셀에서 Ctrl+V를 하면 이미지가 붙여넣어집니다.
- Esc 또는 우클릭으로 취소합니다.

## 처음 설치
```
git clone https://github.com/water-color-korea/screenshot.git
```
그다음 `start.bat`를 실행합니다. 파이썬이 필요하고, Pillow는 자동으로 설치됩니다.

| 파일 | 기능 |
|---|---|
| start.bat | 실행 |
| stop.bat | 종료 |
| update.bat | 최신 버전을 받고 다시 실행 |
| autostart_on.bat / autostart_off.bat | 윈도우 시작 시 자동 실행 켜기 / 끄기 |
