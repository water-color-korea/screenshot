# 영역 캡쳐 프로그램

단축키(기본 **Ctrl+Shift+A**)를 누르고 드래그하면 그 영역을 캡쳐합니다.

- `사진\캡쳐` 폴더에 PNG로 저장합니다.
- 클립보드에 파일과 이미지를 같이 복사합니다.
  - 탐색기에서 Ctrl+V를 하면 파일이 붙여넣어집니다.
  - 카톡, 그림판, 엑셀에서 Ctrl+V를 하면 이미지가 붙여넣어집니다.
- Esc 또는 우클릭으로 취소합니다.
- 캡쳐 화면에서 **1** = 고화질(PNG 원본), **2** = 저용량(JPG)으로 바꿀 수 있습니다. Tab 키로도 전환되며, 마지막에 고른 모드를 기억합니다.

## 트레이 아이콘 (화면 오른쪽 아래)
파란 아이콘을 우클릭하면 아래 메뉴가 나옵니다. 아이콘이 안 보이면 작업표시줄의 ^ 를 눌러 보세요.
- 캡쳐하기 (아이콘을 더블클릭해도 됩니다)
- 고화질 / 저용량 선택
- **단축키 변경**: Ctrl·Shift·Alt·Win 조합 + 키
- 저장 폴더 열기
- **종료**

단축키가 다른 프로그램과 겹치면 꺼지지 않고 단축키 설정 창이 뜹니다. 고른 단축키는 기억됩니다.

## 처음 설치
```
git clone https://github.com/water-color-korea/screenshot.git
```
그다음 `start.bat`를 실행합니다. 파이썬이 필요하고, Pillow는 자동으로 설치됩니다.

| 파일 | 기능 |
|---|---|
| start.bat | 실행 |
| stop.bat | 종료 |
| update.bat | 최신 버전을 받고 다시 실행 |
| autostart_on.bat / autostart_off.bat | 윈도우 시작 시 자동 실행 켜기 / 끄기 |
